## ❓ Question 5:

**“Difference between switchMap and mergeMap?”**

👉 Common RxJS question

### ✅ Strong Answer:

switchMap cancels the previous API call and only keeps the latest one, which is useful for search functionality. mergeMap runs multiple API calls in parallel without canceling them.

---

## ❓ Question 6:

**“How do you prevent memory leaks?”**

### ✅ Strong Answer:

I use takeUntil or async pipe to automatically unsubscribe from observables and clean up subscriptions in ngOnDestroy.
